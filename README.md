# PrintSketch

**Version 1.9.2**

PrintSketch is a tablet-friendly app for designing 3D prints for Bambu Lab printers. This repository holds only the finished app, published with GitHub Pages so it can be installed and used offline.

**Open it:** https://rnclock.github.io/My_Own_App/

On an Android tablet, open the link in Chrome, then ⋮ → **Add to home screen**. On a PC, open it in Chrome or Edge and click the install icon in the address bar. After the first visit it works without internet and updates itself when online.
